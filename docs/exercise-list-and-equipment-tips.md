**Legend**
- ✅ = illustration file exists and is shown on the card
- ❌ coming soon = the card is deliberately marked "Illustration coming soon"
- ❌ file missing = the code points to an image file that doesn't exist in the app (needs the image delivered, or the card switched to "coming soon")
- **Needs** = the card only appears if the user switched that item on in Profile → My Equipment; otherwise the app swaps in the bodyweight version shown after →
- **Tip equipment** = which of the user's equipment can trigger a tip on that card (full tip text in Part 2)
